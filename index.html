Declares the unit in which values of the annotated datatype property are expressed. Values are QUDT unit individuals, so the unit itself is identified by a QUDT IRI and is machine resolvable. A local annotation property is used rather than a QUDT predicate for two reasons. First, qudt:unit is deprecated in QUDT 2.1 and marked dcterms:isReplacedBy qudt:hasUnit. Second, qudt:hasUnit relates a system of units to a unit, which is a different relationship from the one needed here. QUDT provides no predicate for annotating an owl:DatatypeProperty with the unit its values carry, because QUDT expects measurements to be reified as qudt:QuantityValue instances. UTT deliberately records plain xsd:decimal values rather than reified quantity values, since contractors supply flat numeric fields and reification would add a node per measurement for no practical gain.
